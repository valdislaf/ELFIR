I. Архитектура и платформа

x86-64 / AMD64

64-битная архитектура процессоров AMD и Intel

регистры: RAX–R15, RIP, RSP

режимы: long mode, compatibility mode

Ryzen / Intel (микроархитектура)

различия в производительности, latency инструкций

одинаковый ISA (Instruction Set Architecture)

ISA (Instruction Set Architecture)

набор инструкций, видимых программисту

SSE, AVX, AVX2, FMA, AES и т.д.

WSL1 vs WSL2

WSL1 — системные вызовы транслируются

WSL2 — реальное Linux-ядро (VM)

отличие в совместимости ELF и perf/debug

II. Формат исполняемых файлов

ELF (Executable and Linkable Format)

стандартный формат бинарников в Linux

типы: ET_EXEC, ET_DYN, ET_REL

ELF64

64-битная версия ELF

адреса, заголовки, таблицы

Sections (секции ELF)

.text, .rodata, .data, .bss

.plt, .got, .rela.plt

Segments (програмные сегменты)

LOAD, DYNAMIC, INTERP

отличие секций от сегментов

Relocations (релокации)

R_X86_64_PC32

R_X86_64_GOTPCREL

зачем нужны и кто их применяет

III. PIC / PIE / адресация

PIC (Position Independent Code)

код, не зависящий от абсолютных адресов

используется в shared libraries (.so)

PIE (Position Independent Executable)

исполняемый файл, загружаемый по случайному адресу

ASLR, безопасность

ASLR (Address Space Layout Randomization)

рандомизация адресов в памяти

защита от exploit’ов

RIP-relative addressing

адресация относительно RIP

lea rdi, [rel msg]

default rel (NASM)

директива синтаксиса

не равно PIE

IV. Линковка и динамическая загрузка

Static linking

всё включено в бинарник

большой размер, нет libc.so

Dynamic linking

libc, ld-linux, shared libraries

загрузка во время запуска

ld (linker)

связывает объектные файлы

создаёт ELF

gcc как драйвер

gcc ≠ компилятор

вызывает as, ld, collect2

Dynamic Loader (ld-linux-x86-64.so.2)

загружает .so

резолвит символы

V. PLT / GOT / символы

Symbol (символ)

имя функции/переменной

локальный / глобальный / undefined

PLT (Procedure Linkage Table)

таблица переходов для функций

puts@plt

GOT (Global Offset Table)

таблица адресов

используется вместе с PLT

Lazy binding

функция резолвится при первом вызове

wrt ..plt / @plt (NASM)

явный вызов через PLT

обязателен для PIE

VI. ABI и соглашения вызовов

ABI (Application Binary Interface)

бинарный контракт

регистры, стек, выравнивание

SysV x86-64 ABI

стандарт Linux для x86-64

Calling Convention

RDI, RSI, RDX, RCX, R8, R9

return → RAX

Stack alignment

16-байтное выравнивание перед call

критично для SSE/AVX

Red Zone

128 байт под RSP (Linux)

отсутствует в Windows ABI

VII. Variadic и связанные нюансы

Variadic functions

функции с переменным числом аргументов

printf, scanf

AL / EAX for variadic

количество XMM-регистров

обязательное обнуление AL

puts vs printf

puts — не variadic

printf — variadic
