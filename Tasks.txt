Задача 1 — многопортовая структура + helpers (Этап 1)
Задача 1/4: Добавь поддержку N устройств: память + метаданные + helpers.

Требования:
- Зарезервировать в rt_xhci_scratch_bufs области:
  usb_kbd_ring_pool, usb_kbd_buf_pool, usb_kbd_meta_pool
- В meta на одну запись хранить минимум:
  used (0/1), ep_id (u64), ep_addr (u8/u64), slot_id (i64), port_id (i64),
  db_slot (u32/u64), ring_ptr (ptr<u32>/u64), buf_ptr (ptr<u8>/u64),
  ring_idx (i64), ring_cycle (i64), pending (i64)
- Лимит: usb_kbd_max_devs = 4 (константа).
- Реализовать helpers:
  usb_kbd_alloc_handle() -> i64 (0..N-1 или -1)
  usb_kbd_find_by_ep(u64 ep_id) -> i64 (или -1)
  usb_kbd_meta_load/store(field) или набор usb_kbd_get_* / usb_kbd_set_*
  usb_kbd_ring_ptr(handle), usb_kbd_buf_ptr(handle)

Ничего из enumerator/evt_poll пока не менять.

Задача 2 — переписать перечисление портов (Этап 2)
Задача 2/4: Перепиши цикл перечисления портов: регистрируй ВСЕ HID boot keyboard до лимита.

Требования:
- Убрать ранний выход после первой клавиатуры.
- Пройти все порты (или до конца списка), для каждого устройства HID boot keyboard:
  - получить handle = usb_kbd_alloc_handle()
  - если handle == -1 → пропустить дальнейшую регистрацию, продолжить сканировать порты
  - сохранить в meta: port_id, slot_id, ep_id, ep_addr, db_slot/doorbell pointer (что у тебя используется)
- Существующую настройку slot/endpoint/context для одной клавиатуры расширить так,
  чтобы выполнялась для каждой найденной клавиатуры и писала результаты в meta[handle].
- В конце регистрации каждого устройства подготовить его ring/buf из pools (по handle),
  но НЕ переписывать xhci_evt_poll и очередь передач.

Критерии:
- usb_kbd_dev_cnt увеличивается на каждую успешную регистрацию (≤ usb_kbd_max_devs).
- Логи/метки (если есть) показывают регистрацию нескольких клавиатур.

Задача 3 — очередь передач + события (Этап 3)
Задача 3/4: Перепиши очередь передач и обработку событий под несколько устройств.

Требования:
- Убрать зависимость от одного глобального usb_ep_id / usb_kbd_ring / usb_pending.
- Передача:
  - пройти по handle=0..usb_kbd_max_devs-1, если meta.used==1:
    - если meta.pending==0 → сформировать TRB и enqueue в ring для ЭТОГО handle
    - сделать doorbell для ЭТОГО устройства (используя meta.db_slot/doorbell)
    - выставить meta.pending=1 и сохранить ring_idx/cycle
- События:
  - в xhci_evt_poll при ev_epu:
    - handle = usb_kbd_find_by_ep(ev_epu)
    - если handle != -1 → обработать HID report из buf для этого handle
      и вызвать line_apply_char(...)
      затем meta.pending=0
- Repeat можно оставить глобальным (как сейчас), но не ломать ввод.

Критерии:
- при двух клавиатурах на разных портах символы приходят с обеих.
